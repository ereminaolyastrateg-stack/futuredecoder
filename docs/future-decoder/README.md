# Разбор игр для цифрового сада Future Decoder

Версия: 1.0 · 11 ноября 2026

Основной рабочий документ — [единый шаблон разбора транскрипта](TRANSCRIPT_ANALYSIS_TEMPLATE.md). Один заполненный разбор собирает материал игры и задаёт, какие существующие файлы обновить и какие новые карточки нужны.

## Комплект

| Файл | Назначение |
|---|---|
| [TRANSCRIPT_ANALYSIS_TEMPLATE.md](TRANSCRIPT_ANALYSIS_TEMPLATE.md) | Полный разбор игры: источники, содержательные фрагменты, сигналы и произведения, макротренды, сценарии, сферы, предложения людей, вопросы и распределение по файлам |
| [CARD_UPDATE_TEMPLATE.md](CARD_UPDATE_TEMPLATE.md) | Подготовка конкретного изменения существующей карточки или создания новой; заготовки для разных типов материалов |
| [QUARTZ_LINKS.md](QUARTZ_LINKS.md) | Постоянные номера, пути, ссылки на сигнал внутри обзора, обратные переходы и проверка ссылок |

## Порядок работы

1. Получить транскрипты и установить границы одной игры. Найти доступную сводную базу 82 макротрендов, стартовые описания сценариев, соответствующий обзор сигналов и, когда понадобится, тест 132.
2. Заполнить единый разбор. Сохранить все содержательные мысли, примеры, несогласия, желания и предложения; отдельно отметить слова участников и аналитические связи.
3. По разбору составить список затронутых макротрендов, сценариев, сфер, сигналов и произведений. Проверить имеющиеся материалы. Ольге выдать только список того, что действительно ещё нужно загрузить.
4. Подготовить изменения карточек по CARD_UPDATE_TEMPLATE.md. Начинать с затронутых карточек макротрендов и сфер, затем обновлять сводные страницы и общие сценарии. Параллельно дополнять медиатеку.
5. Сохранить происхождение выводов в карточке игры. Проверить все переходы и доступность целей ссылок перед публикацией.

Первый этап можно закончить без исходных карточек сфер: фиксируем последствия и временно не определённые связи. Точные восемь сфер и их границы берём из авторского материала, а не придумываем по теме игры.

## Договорённости

- Сигналы хранятся разделами внутри обзоров. Отдельные файлы сигналов не создаются по умолчанию.
- У сигнала постоянный номер и заголовок; связь ведёт к этому разделу, а не только к обзору целиком.
- Подготовленный сигнал не обязательно обсуждался на игре.
- Книга или фильм могут быть культурным сигналом, примером мира, источником идеи или ассоциацией участника. Роль фиксируется в каждом обсуждении.
- Предложения людей сохраняются в сценарных карточках макротрендов и сфер. Отдельные карточки действий появляются после независимых повторов. Отображение одной идеи в нескольких файлах повтором не считается.
- Полный транскрипт, краткая цитата, пересказ, аналитический вывод и внешний источник различаются.
- Утверждения, отсутствие которых установлено только для одной игры, не обобщаются на весь сад.
- Все 328 сочетаний «макротренд × сценарий» и 32 сочетания «сфера × сценарий» не заполняются автоматически из одной игры.

## Стартовые материалы по образованию

Обзор в текущем черновике: [content/signals/education.md](../../content/signals/education.md).

В нём 40 сигналов с заголовками SIG-EDU-001…SIG-EDU-040. Исходная сценарная разметка сохранена, связи с макротрендами предварительные, привязка к восьми сферам ещё не заполнена. Две позиции требуют дополнительной проверки источников. Эти ограничения учитываются при разборе.

Пример адреса конкретного сигнала: [TUMO Path — SIG-EDU-005](../../content/signals/education.md#sig-edu-005). Это пример навигации, а не утверждение, что сигнал уже обсуждался в полученной игре.

## Сохранение результата

Шаблоны находятся вне content и не являются страницами читательского сада. Заполненный рабочий разбор также не публикуется автоматически. Исходные транскрипты не копируются в публичный репозиторий автоматически; сохраняются ссылки на полученные материалы. Для сада готовится карточка игры с содержательными выводами и подходящими для публикации фрагментами.
