# Правила работы с садом futuredecoder.org

Сад Оли Ерёминой (Декодер Будущего) на Quartz v5, ветка `v5`, публикуется GitHub Pages примерно за 3 минуты после push. Локальная сборка Quartz зависает — проверять через `gh run list` и живой сайт.

## Как оформляем
- **Большие наборы — таблицей с фильтрами, а не списком.** Сигналы, медиатека, макротренды, сферы жизни показываются каталогом с поиском и фильтрами (компоненты `SignalCatalog`, `MediaLibraryCatalog`, `CardCatalog`). Новый вид заметок с десятками элементов — новый каталог. Папку такого раздела сворачиваем в проводнике (`custom.scss`).
- **Два языка всегда.** Всё, что выкладываем, сразу делаем на русском и английском, с `translations` в шапке.
- **Цеттелькастен.** Иерархические теги (`тип/`, `сценарий/`, `сфера/`, `тема/`, `макротренд/`), полные вики-ссылки `[[путь|текст]]`, сигналы ссылаются на мир, сферу и макротренд своего мира.
- **Тексты карточек:** сцена 2035 года с людьми → откуда мы идём → каким становится мир → что даёт и чем платишь → сигналы → что нашли на играх (лесенка тезисов с цитатами) → что сделать → другие миры. Без нагромождения оговорок и служебного текста.
- **Этика:** без имён участников игр, без политики и частной жизни; цитаты сверяем с транскриптом.
