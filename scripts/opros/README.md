# Опросник «Как сейчас и каким хочу»

Статичная страница `quartz/static/opros/` (RU) и `quartz/static/opros/en/` (EN), описание в саду: `content/opros/index.md` и `content/en/questionnaire/index.md`.

- Варианты берутся из карточек сфер жизни: `scripts/spheres/source_ru.json` + `tr_en.json`. Примеры со статусом «Кандидат…» не выгружаются, на вариант берётся не больше двух.
- Обе страницы собираются из `template.html`. Правишь шаблон или карточки, потом запускаешь `python3 scripts/opros/build.py`.
- Данные человека никуда не отправляются. Черновик хранится в `localStorage` (ключ `fd-opros-v1`), итог выгружается в `.md`, в `.json` (формат `futuredecoder-opros/1`, для бота) и на печать.

## Мини-истории

Варианты в опроснике показываются как история из одного предложения от «я» на базе свежего сигнала (`stories.json`, ключ = id карточки). Правила: одно предложение, без рода («сама», «готова» нельзя), в мирах правил и сообщества — маркер будущего, чтобы мастер, кружок, соседство не читались как прошлое. Сигналы пополняются: заменил запись в `stories.json`, пересобрал `build.py`.

## Отложено: заметка «Почему мир сообщества — не про прошлое»

Идея: многие практики мира сообщества выглядят как возврат к старому (мастер, ремесло, кружок, соседство). Это ретро-инновации: старая форма на новой инфраструктуре. Заметку пишем позже, RU + EN, ссылаемся на неё из опросника рядом с вариантами мира сообщества.

Черновые определения «раньше — теперь»:
- **Мастер** — держит качество и вкус, когда рутину делает машина; работает и руками, и на цифровых станках.
- **Ремесло** — малые серии и вещи под человека, руками вместе с цифровыми инструментами (фаблаб, 3D-печать, заказ онлайн).
- **Сообщество** — добровольная сеть по делу или интересу: общие правила, деньги, решения и право выйти. Не секта и не обязанность.
- **Соседство** — выбираемый ресурс: общие пространства, библиотеки вещей, банки времени, энергетические сообщества.
- **Учебный круг** — группа равных, онлайн и вживую, ведёт один из участников.

Сигналы в пример: библиотеки вещей, банки времени, 8000+ энергосообществ в ЕС, Telraam, «третьи места» во Франции, инициативный бюджет.

## Продолжение (вкладка «Дальше», `#lab`)

Короткая автоматическая версия лаборатории, пять шагов: выбрать до 10 «хочу» минимум из двух сфер → «Зачем» (до трёх ценностей из 12 + своё слово) → «Грозовые тучи» (любая пара из разных миров спорит о том, кто решает; диагональ и конфликт ценностей усиливают; если все «хочу» из одного мира — туча между этой целью и остальной жизнью) → «Ресурсы» (у каждого желания «нужно: есть / не хватает» и «даёт») → «Карта» (схема желаний и ресурсов: горлышко, место для рычага, петля или замкнутый круг, главная туча и четыре способа добыть ресурс без него самого с сигналами из карточек — словарь `RW`). Всё в том же `localStorage`, попадает в .md и .json.

## Продолжение, версия «полный круг» (ноябрь 2026)

Шесть шагов: Выбрать → Зачем → Тучи → Рычаг → Дороги → Карта. Необязательное продолжение: Система → Следствия → Джокер → Полный круг.

- `steps.json` — первый шаг для карточек (пилот: F1–F4, B1, C1): шаг, «кто уже так» (сигнал или ответ с игры), без какого ресурса.
- `values.json` — 12 ценностей: что это такое и примеры с игр (пары «id вопроса Полотна + мир»), build.py подтягивает цитату, мысль и шаг из `quartz/static/polotno/data.json`.
- `tales.json` — истории: фильмы, книги, реальные кейсы с тегами миров, ценностей и сфер. На карте подбирается похожая по рычагу и миру первого шага.
- В шаблоне: блок «Как мозг меняет картину будущего» со ссылками на исследования, «Что в основе» (матрица 2×2 и книги), честные «как сейчас» по сферам, творческие задания, 16 джокеров, PDF карты (SVG → canvas → html2pdf).

## Продолжение, версия «Мир → Ситуация → Вещь» (прототип)

Короткая часть, 9 шагов: выбрать → откуда и зачем (источник желания, ценности, «не моё») → рычаг (схема, примеры с игр, где ценность уже есть) → вопросы-тучи «Как мне получить [рычаг] через [хочу], не [ограничение]?» (до 5, разбираем 1–2) → разбор (туча Голдратта, решения в 4 логиках, сначала обходящие ограничение, забытые практики, своё) → день А и Б (аудит «есть»: функция / помогает-мешает / сложность, честные чипы, черновик дней) → шаг под лупой (COM-B, лесенка быстрый/средний/трудный, кого позвать, критерий успеха) → история и вещь (путешествие во времени, вещь-пожелание) → карта + карточка-обещание в PDF.
Возврат, 4 шага: встроить (сфера, ±, что помешает, обратная связь, ожидаемая точка А) → петли (следствия, R, задержка, цикл) → джокер → пересмотр (эскиз/каркас/структура, люди/наблюдения/цифры, фактическая точка А, новый круг).
Строки — `T.lb2`, состояние — новые поля в `LAB0()`.

## Версия 3: поле рычагов
Хочу → как сейчас (аудит + свои пункты) → два дня и «что правда хочу» → ценности и источники → с чего начать (1–2 ценности) → тучи (до 3) → разбор туч: кандидаты в рычаги (смена картины из «если неправда», сигналы, примеры с игр, своё, минимальный шаг, забытые практики) → поле рычагов по уровням (действие / правило или привычка / смена картины) → история и вещь → встроить (сфера, ±, плюсы и минусы, что помешает, с чего завтра) → обратная связь (что увижу, новая А, дата; «ещё один рычаг») → картина `picSVG` (А → тучи → рычаги → шаг → новая А / обратная связь → Б) и обещание. Дальше по желанию: петли, джокер, пересмотр.

## Версия 4 (текущая): 8 шагов и карта, которая растёт
Хочу (ситуация, своё «хочу», карточки) → Как сейчас (описание по сферам с примерами) → День Б (путешествие, «не моё») → Ради чего (ценности, кластеры, 1–2 ценности) → Убеждения и тучи (шаблоны убеждений, «откуда», «почему», «а если неправда», общий корень; туча по Голдратту по кнопке; примеры с игр) → Поле рычагов (свои, «хочу», сигналы, уровни задаёт человек, «что ещё закрывает», финалисты) → Система (финалисты в центре, связи +/− с ценностями, «хочу», убеждениями, тучами, сферами; выбор рычага; петля и задержка) → Эксперимент (COM-B, премортем, «когда…, я…», результат, новая А, люди, дата + .ics, картина, обещание, вещь, предложения разбора и лаборатории). По желанию: джокер, пересмотр. Строки — `T.lb2.v4`, картина — `picSVG(hl)`.

## Версия 5 (текущая): 6 шагов
Хочу (свои «хочу» + карточки; у каждого сразу «ради чего» и «откуда») → Как сейчас (по сферам) → День Б (путешествие, «не моё», в конце выбор 1–2 ценностей) → Поиск рычагов (убеждения со списками «хочу»/ресурсов, тучи со списками, «что уже получается», примеры с игр, своя идея; уровень ставится сразу; в конце поле «Ваши рычаги», выбор до трёх) → Система-ромашка (я + 8 сфер с «как сейчас», клики по лепесткам +/−, подсказка сильнейшего рычага, петли и задержка с подсказкой из ответов) → Эксперимент (у каждого блока «зачем»), картина, обещание, вещь, предложения. Рисунок «как мозг меняет картину» показывает, что можно сделать самому и что добавляет лаборатория. Строки — `T.lb2.v5`.

## Версия 6 (текущая): опрос внутри лаборатории
Страница открывается сразу на лаборатории (вкладки опроса скрыты). Как сейчас (8 сфер, тезисы через «;») → Хочу (по сферам: свои «хочу», карточки миров с ответами хочу / есть-сохранить / есть-убрать / не про меня, у «хочу» — ради чего и откуда) → День Б (+ выбор ценностей) → Поиск рычагов (списки из всего написанного: как сейчас, хочу, сохранить/убрать, ценности, ресурсы; готовые тучи; рычаг выбирается и без уровня) → Система (схема: сферы → как сейчас → рычаги → хочу → ради чего → итог по сферам; клики по узлам; свободные поля; карта года по кварталам) → Эксперимент. Строки — `T.lb2.v6`, схема — `sysFlowSVG()`, карта года — `yearHTML()`.
