# Сферы жизни (8 сфер × 4 мира)

Источник — файл «Future_Decoder_v12_132», листы «Тест · 132» и «Справочник v7».

1. `source_ru.json` — выгрузка: ситуация человека, короткое название, плюсы, цена, ресурсы, вопросы и граница подсферы, примеры с источником. Примеры со статусом «Кандидат для теста — не подтверждён как сигнал» не выгружаются.
2. `tr_en.json` — английский перевод тех же полей по id карточки (H1-ЦС и т. д.) и по названию подсферы.
3. `python3 scripts/spheres/build.py` — пересобирает `content/chetyre-mira/sfery/` и `content/en/four-worlds/life-spheres/`.

При правке карточки в Excel: обновить `source_ru.json` (или выгрузить заново), поправить перевод в `tr_en.json`, запустить сборку.
Сигналы ссылаются на сферы через `scripts/signals/split.py` (SPHERE_NOTES).
