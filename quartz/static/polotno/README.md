# Полотно будущего

Страница полотна для цифрового сада Декодера.

- `index.html` — сама страница (дизайн и игры).
- `data.json` — база знаний: вопросы, четыре мира, сигналы, смеси и парадоксы.

## Где лежит

В репозитории сада: `quartz/static/polotno/`.
Адрес после публикации: https://ereminaolyastrateg-stack.github.io/futuredecoder/static/polotno/

## Как обновить базу

Заменить только `data.json` в той же папке. Страницу трогать не нужно.

Строка вопроса скрывается с сайта, если у вопроса стоит `"show": false`.
